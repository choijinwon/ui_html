# ui_html

`golden-image` 정적 HTML 화면입니다.

## 기준

- `index.html`이 기준 화면입니다.
- 좌측 메뉴의 `golden-image`는 4개 탭 화면에서 active 상태입니다.
- 좌측 메뉴는 `golden-image` 한 개만 표시합니다.
- 4개 탭은 `golden-image` 화면 내부의 탭 구조로 표시됩니다.
- API 연동 없이 `golden-image.js`의 샘플 데이터가 바로 보입니다.
- 등록/수정/삭제 데이터는 브라우저 `localStorage`에 저장됩니다.

## 탭 화면

- `index.html` - Release Dashboard
- `families.html` - Golden Families
- `components.html` - Component Catalog
- `matrix.html` - Compatibility Matrix

## 공통 파일

- `styles.css`
- `golden-image.js`
